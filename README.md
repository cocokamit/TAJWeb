# TAJ marketing website

React + Vite one-page site for The Adventurer's Journey. 3D hero with three.js
(react-three-fiber), scroll animations with framer-motion, smooth scrolling with Lenis.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

Deploys on Vercel as a Vite project with the default settings.

The join form sends nothing until `SIGNUP_ENDPOINT` in `src/config.js` is set.
